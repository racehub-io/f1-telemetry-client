# Contributing

- Open an issue with the problem and the expected result. Include the package version, Node.js version, and game version.
- Keep each pull request small. Explain the change and the checks you ran.
- Run `npm ci` and `npm test -- --runInBand` before you submit code changes.
- Keep credentials, account data, and private recordings out of source, logs, and test files.
- Preserve third-party notices. State the origin and licence of copied material.
- State that you offer new original contributions under CC0 1.0. Only grant rights that you own. Keep existing terms for third-party changes.
- Use respectful, direct language. Maintenance depends on volunteer time. No response time or release date is promised.

See [LICENSING.md](LICENSING.md) and [SECURITY.md](SECURITY.md).
